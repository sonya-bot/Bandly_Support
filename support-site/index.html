BANDLY SUPPORT / 日本語

Bandlyを使うための
サポートガイド。

音源の取り込みから、再生・録音、データの管理まで。使い方や困ったときの確認方法をご案内します。

よくある質問を見るお問い合わせ

できることから、探す。

iPhone向け・iOS 17.0以降

01 / 分離・再生

音源を取り込み、パートごとに聴く

同梱のBandly Baseで7パートに分離。パートの音量調整、再生速度・キーの変更、A–Bループを使えます。

取り込み方法を確認する →

02 / チューナー

マイク入力で音の高さを確認する

チューナーの設定や、入力機器を確認できます。音を拾わないときは、マイクの使用許可と入出力設定をご確認ください。

マイクの確認方法 →

03 / 録音・測定

演奏や測定結果を残す

曲に合わせた録音テイクや単体のメモ録音を保存。周波数特性の測定・結果の保存と書き出しにも対応しています。

書き出したファイルの場所 →

04 / データの管理

端末内のデータを確認する

曲・録音・測定結果は端末内に保存します。ストレージ使用量の確認や、不要なデータの削除ができます。

データの削除方法 →

データの取り扱いについて

アプリ内の処理・保存、共有操作、サポートサイトのアクセス情報について説明しています。
